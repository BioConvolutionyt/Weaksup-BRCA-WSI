# 6.4 面积硬约束与空间平滑的"张力"（探索笔记）

> 文档 6.4：软性 MSE 只要求"接近"，不保证硬性满足。若把面积约束写成硬性等式、
> 同时要求空间平滑，问题在数学上变成什么？N≈10⁴–10⁵ 时精确求解的计算瓶颈？
> 能否设计近似策略，使面积误差 ≤0.03 且连通域显著少于简单阈值法？

## 1. 问题定义

交付管线的 mask 由"分数阈值 0.5 + 形态学"产生：面积是**软**约束（mask 占比与
预测占比实测平均偏差 0.132），且阈值法的连通域数受分数场噪声影响。本探索问：
能否让 mask **精确**承载预测面积、同时空间上成团？这两个要求能否同时满足？

## 2. 初步思路与数学形式化

### 2.1 从需求到优化问题：每个符号是什么

交付模型为每张切片输出 N 个 patch 的肿瘤分数 s_i∈[0,1] 和一个袋级预测占比
f̂。我们要的 mask 是一个**二值选择向量** x∈{0,1}^N（x_i=1 表示"判为肿瘤"），
它要同时满足两个诉求：

1. **选高分 patch**（肿瘤证据）：最大化 Σ_i s_i·x_i——选中的 patch 分数越高越好；
2. **空间成团**（平滑）：相邻 patch 的判定应一致。把 patch 按网格 8 邻接连成图
   (V, E)，对每条边 (i,j)∈E 惩罚 |x_i−x_j|（判定不一致则罚 1）——这就是
   **Potts/Ising 能量**，λ 控制平滑强度；
3. **面积硬约束**：选中个数必须恰好等于预测面积预算 Σ_i x_i = K，
   K = round(f̂·N)。

合起来：

$$\max_{x\in\{0,1\}^N}\ \sum_i s_i x_i \;-\; \lambda \sum_{(i,j)\in E} |x_i-x_j| \quad \text{s.t. } \sum_i x_i = K$$

理解这个问题的关键是：**两个诉求单独看都容易，合起来就难**。

### 2.2 数学基础一：为什么"只有平滑"时精确可解（s-t 最小割）

先去掉基数约束，只留目标函数（等价于最小化其相反数）。二元变量 + 一元项 +
两两 Potts 项的能量最小化，可以**精确**转化为图上的 s-t 最小割：

- **建图**：每个 patch 是一个节点；额外加源点 s（"肿瘤"）与汇点 t（"背景"）。
  一元项变成 t-边：节点 i 到 s、t 各连一条边，容量取"判 0 / 判 1 的代价"
  （如 D_i(1)=−log s_i，D_i(0)=−log(1−s_i)）；每条邻接边 (i,j) 连一条容量 λ 的
  n-边。
- **割 = 判定**：一个 s-t 割把节点分成 s 侧与 t 侧，即一种 0/1 判定；割的代价
  （被切断的边容量之和）恰好等于该判定的能量——t-边被割 ⇔ 付出一元代价，
  n-边被割 ⇔ 相邻判定不一致、付出 λ。
- **为什么能精确解**：Potts 项满足**子模条件** E(0,0)+E(1,1) ≤ E(0,1)+E(1,0)
  （0+0 ≤ λ+λ，即"一致比不一致便宜"）。Kolmogorov & Zabih (2004) 证明：
  满足子模条件的二元两两能量都可图表示、可用最大流/最小割在**多项式时间**
  求到全局最优（实际中 Boykov–Kolmogorov 算法在 10⁵ 节点的网格图上约秒级）。

### 2.3 数学基础二：为什么"加上面积约束"就变 NP-hard

- **基数约束是全局耦合**：Σx=K 把全部 N 个变量捆在一起——任何一个位置判 1
  都消耗全局预算。而最小割的代价是**逐边局部求和**的，没有任何局部边结构能
  表达"恰好 K 个节点落在 t 侧"这种全局计数条件，§2.2 的建图方法就此失效。
- **已知难题的亲戚**：带基数约束的划分问题中，"最小二等分"（把图分成恰好
  各一半、割最小）是经典 NP-hard；我们的问题可看作它的加权推广。
  另外，单看目标：Σ s_i x_i 是**模函数**（可逐个独立相加），单独的基数约束下
  最优就是排序取前 K（这正是 S2 贪心，精确最优！）；但 −λ·割 这一项是
  **超模**方向，叠加后目标既非单调也非子模，连贪心 (1−1/e) 的经典近似保证
  都不再适用。
- **精确算法的复杂度墙**：2D 网格图的 treewidth ≈ √N（N=10⁴ 时约 100），
  基于树分解的精确动态规划需要 O(N·2^√N) 量级状态——2^100 是不可行的；
  整数规划分支定界最坏指数。**结论：N≈10⁴–10⁵ 时精确求解不可行**。
- **一句话总结张力**：平滑单独容易（最小割），面积单独容易（排序取前 K），
  二者耦合后 NP-hard——这就是文档所问"张力"的数学本质。

### 2.4 数学基础三：拉格朗日松弛——S4 的原理与对偶间隙

精确不可行，退而求其次：把硬约束乘上乘子 γ 放进目标（拉格朗日松弛）：

$$\max_x\ \sum_i (s_i+\gamma)\, x_i \;-\; \lambda \sum_{(i,j)\in E} |x_i-x_j| \;-\; \gamma K$$

- **γ 是"选区价格"**：每选一个 patch 额外付 γ。γ 大 → 选得少；γ 小 → 选得多。
  对任意**固定**的 γ，问题退回 §2.2 的无约束子模能量，一次最小割精确求解；
- **二分 γ 逼近 K**：选中数 |x*(γ)| 是 γ 的单调不增函数，于是二分搜索 γ
  （我们取 γ∈[−6,6]、22 次迭代）即可逼近预算 K；
- **对偶间隙（为什么不能保证恰好 K）**：|x*(γ)| 是**阶梯函数**而非连续函数——
  平滑项把成片 patch 绑定在一起，γ 跨过某个临界值时选区会整块整块地翻转，
  选中数可能从 K+δ₁ 直接跳到 K−δ₂，**不存在使选中数恰为 K 的 γ**。松弛问题
  的最优值 ≥ 原问题最优值，二者之差即对偶间隙——这是离散（非凸）问题
  拉格朗日松弛的固有性质，也是 S4 面积误差只能≈0.004 而不能恒为 0 的原因；
  β（平滑权重）越大，阶梯跳变越猛、间隙越宽——这正解释了 β 扫描中
  β=0.9 时面积误差反而上升的现象。

### 2.5 四条候选路线

① **简单阈值**（现状）：x_i = [s_i ≥ 0.5]——完全不管面积约束；
② **Top-K 贪心**：排序取前 K——面积构造上精确，但放弃了平滑
（§2.3：它是"只留面积约束"的精确解）；
③ **图传播平滑 + Top-K**：先把分数沿空间-特征图传播变平滑，再取前 K——
把平滑先验"融进分数"再精确预算，是两个容易解法的序贯组合；
④ **拉格朗日图割**（§2.4）：唯一一个在同一目标里同时优化证据与平滑、
仅对基数做松弛的"原理性近似"。②③④ 对比 ①，纯 CPU 后处理、不重训。

## 3. 实验结果

分数图 = 交付配置（75 张面积口径 + q75 + 可信度 + 平滑 λ=0.01）OOF patch 分数
（Pearson 0.801 / Spearman 0.793，与实验十三复现一致）。四策略 + 强化变体：

| 策略 | 面积误差 | 连通域数 | mask 邻域差异 | 单张耗时 |
|---|---|---|---|---|
| S1 简单阈值 0.5 | 0.1323（**不达标**） | **14.2** | 0.0495 | <0.1s |
| S2 Top-K 贪心 | 0.0263 ✓ | 35.0 | 0.0677 | <0.1s |
| S3 传播×1 + Top-K | 0.0158 ✓ | 33.4 | 0.0609 | ~1s |
| S3b 传播×3 + Top-K | 0.0073 ✓ | 30.1 | 0.0528 | ~2s |
| **S4 拉格朗日图割 β=0.3** | **0.0037** ✓ | **26.0** | **0.0224** | ~1.3s |

β 扫描（9 代表切片子集）：β∈[0.1,0.9] 面积误差 0.003–0.02、连通域稳定 ≈26；
β=0.9 时面积误差升至 0.0196（对偶间隙显形）而连通域不减——**平滑拨盘的
边际收益耗尽、只余面积代价**，张力曲线平坦段即"Pareto 前沿底"。

产物：`6.4_metrics.csv`、`6.4_pareto.csv/png`、`6.4_mask_*.png`（3 张代表切片对比）、
`6.4_scores.npz`（可复算）、`6.1_credibility_real75.csv`（顺带导出的逐切片可信度，

## 4. 结论（文档三问）

1. **数学上变成什么**：基数约束的 Potts/MAP-MRF——无约束时图割可解，
   加硬面积约束后 NP-hard；瓶颈 = 全局基数 × 局部平滑的耦合
   （N=10⁴–10⁵ 时精确法指数不可行，对偶松弛有间隙）。
2. **近似策略达标情况**：**S4 与 S3b 均达面积误差 ≤0.03**（0.004 / 0.007，
   优于目标 4–8 倍）；连通域上，面积可行的方法（26–35）**无法少于**
   简单阈值法（14.2）——因为阈值的低连通域恰恰来自它**放弃面积约束**
   （只取高置信核心，面积偏差 0.132）。文档的双重目标在本数据上不可同时
   达到，这本身就是"张力"的实证。
3. **推荐**：交付 mask 改用 **S3b（传播×3 + Top-K + 形态学）**——面积精确
   （0.007）、连通域较阈值法同量级、零额外依赖、每张 ~2s；S4 图割作为
   "原理性最优近似"入档（面积最精、边界最平滑），PyMaxflow 为可选依赖。

**排错记录**：S4 首版把 source/sink 侧读反（get_segment==0 实为未选中侧），
导致 mask 取补集、面积误差 0.466——修正后图割精确命中预算，验证了
"对偶偏差 γ 控制基数"的机制按预期工作。

## 5. 最关键的阻塞点 & 若多一倍资源

- **阻塞点**：连通域数的"地板"由肿瘤本身的多灶性决定（乳腺癌 WSI 常多灶），
  后处理无法在不牺牲面积的前提下压到阈值法水平——这是问题内禀，非方法缺陷。
- **多一倍时间**：① 把 S4 的一元项换成 SRG 校准后的分数（当前用原始 sigmoid
  分数）；② 在 mask 层面做连通域级贪心（按区域总分排序选区直到预算耗尽），
  有望进一步降连通域；③ 对 β 做逐切片自适应（按分数场方差定标）。
