# 6.2 池化硬度 × WSI patch 数 N 的最优匹配（探索笔记）

> 文档 6.2：平均池化稀释信号、最大池化忽略面积——两极之间是否存在"最优硬度"？
> 硬度应随 patch 数 N 变化吗？能否让硬度在训练中自动调整（数据驱动调度）？
> 固定池化形式下，回归误差与 N 呈什么经验关系？能否用统计学习理论解释？

## 1. 问题定义

6.3 已回答"硬度 × 标签噪声"（软池化鲁棒、硬池化敏感），但 N 维度未动：
WSI 的 patch 数从 ~10³ 到 ~4×10⁴ 不等，池化器的最优硬度是否随 N 漂移？
若会，聚合器就该按 N 调参；若不会，固定硬度即可——这直接决定交付管线
是否需要 N 自适应聚合。

## 2. 初步思路与实验设计

**理论预期（bias–variance 框架）**：软池化（mean）的稀释偏差与 N 无关
（比例标签下 mean 是无偏的）但判别信号被摊薄；硬池化（max/top-k 固定 k）的
有效实例数 n_eff≈k 不随 N 增长，且 k 固定时等效硬度随 N 上升（top-50 在
N=1000 时是 top 5%，在 N=3万 时是 top 0.17%）；固定比例池化（q75）的
n_eff=0.25N 随 N 线性增长且硬度恒定。由此预测：**固定比例池化 N-不变，
固定个数池化随 N 退化**——实验内置 q75 vs top-50 对照直接检验。

**矩阵 A（硬度 × N 曲面）**：5 池化器按硬度阶梯 {mean → gmean-p5 → q75 →
top-50 → max} × N ∈ {1000, 2000, 5000, 全量} × 5 折 × 3 种子 = 300 次训练。
**嵌套子采样**（同一切片按固定随机排列取前缀：1000⊂2000⊂5000⊂全量），
N 是唯一变量；25 张面积口径标签；关空间约束/可信度/噪声（与 6.3 同协议）。

**矩阵 B（课程调度，Duffner & Garcia 2020 复现）**：gmean 的 p 随 epoch 线性
1→5（先软后硬：软池化梯度稳定学全局，硬池化后期聚焦判别 patch）；端点
p=1/p=5 在数学上精确等于矩阵 A 的 mean/gmean_p5 全量行（去重复用），
仅新增 1 组 15 次训练。合计 315 次训练，65 min。

## 3. 实验结果

**矩阵 A（Pearson，行=池化器，列=N）**：

| 池化器 | N=1000 | N=2000 | N=5000 | 全量 | 随 N 趋势 |
|---|---|---|---|---|---|
| mean | 0.578 | 0.585 | 0.585 | 0.599 | 平 |
| **gmean_p5** | **0.738** | **0.746** | 0.722 | 0.729 | 平，**全程最优** |
| q75（固定比例） | 0.630 | 0.671 | 0.607 | 0.644 | 平 |
| top-50（固定个数） | 0.615 | 0.585 | 0.538 | **0.518** | **单调退化** |
| max | 0.276 | 0.280 | 0.284 | 0.359 | 全程最差 |

**矩阵 B（全量 N）**：课程 1→5 = Pearson 0.713 / **Spearman 0.723（全场最佳）** /
**MAE 0.1419（全场最佳）**；对照固定 p=1（0.599/0.592/0.163）与
固定 p=5（0.729/0.709/0.148）。

## 4. 结论（文档四问）

1. **最优硬度存在且稳定**：gmean-p5 在每一档 N 上都是最优（0.72–0.75），
   两极皆劣（mean ≈0.59 稀释、max ≈0.28–0.36 崩坏）——与 6.3 干净基线
   结论互证，中间偏软硬度是稳健选择。
2. **硬度不应随 N 变化**：固定比例的 q75 全程 N-不变；固定个数的 top-50
   随 N 单调退化（0.615→0.518）——因其等效硬度随 N 被动升高。
   **正确参数化是"比例"而非"个数"**；若必须用 top-k，k 应与 N 成正比。
3. **课程调度≈固定中间硬度，无净收益**：Pearson 略低于固定 p5
   （0.713 vs 0.729），但 Spearman 与 MAE 全场最佳——排序与校准略优、
   相关略损，整体打平。25 张规模下固定中间硬度已够用，课程调度是
   可接受的等价替代，不必引入额外复杂度。
4. **误差-N 经验关系：平**（除固定个数池化外）。理论解释：比例标签是
   无量纲量，嵌套子采样保持分布不变；q75 在 N=1000 时 n_eff=250 已使
   估计方差 σ²/n_eff 低于标签噪声地板（MAE≈0.14 由标签/模型偏差主导），
   继续增 N 的方差收益观测不到。**工程推论：袋级回归把 patch 子采样到
   1–2k 几乎无损**（gmean_p5：N=1000 时 0.738 vs 全量 0.729），
   对大规模部署是免费的效率收益。

## 5. 最关键的阻塞点 & 若多一倍资源

- **阻塞点**：25 张切片的标签噪声地板（MAE≈0.14）掩盖了 σ²/n_eff 的
  细微方差效应——误差-N 曲线的"平"部分是"效应小于噪声"，而非严格证明
  效应为零；N<500 的极端区（方差主导区）未探测。
- **多一倍资源**：① 补 N∈{100, 250, 500} 极端档，定位方差主导拐点；
  ② 在 6.1 的合成真值平台上重做硬度 × N（无标签噪声，方差曲线应显形）；
  ③ 课程调度换更长的预热与余弦时间表，并在大队列（75 张）上复测。
