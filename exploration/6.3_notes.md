# 6.3 探索笔记：极端池化是否天然抵抗标签误差？

> 按文档 6.5 五要素组织。实验日期：2026-08-23。数据：25 张 TCGA-BRCA（面积口径标签）。

## 1. 问题定义

袋级（slide 级）回归标签含噪时，MIL 的池化函数选择如何影响模型的噪声敏感性？文档提出的具体假设是："Top-1 最大池化只关注单个最高分 patch，天然忽略大部分 patch 信息——是否意味着最大池化对标签噪声更鲁棒？"本实验检验该假设在**袋级占比回归**设定下是否成立，并推导不同池化函数的估计误差方差与噪声方差 σ² 的关系。

## 2. 初步思路与技术路线

**理论推导（先行）**：设袋级标签噪声 ε ~ (0, σ²)，MSE 损失下参数扰动与池化权重 w 的模长相关：扰动方差 ∝ σ²·‖w‖² = σ²/n_eff。各池化的有效参与实例数：
- mean：‖w‖² = 1/N → 扰动 ∝ σ²/N（稀释）；
- max：‖w‖² = 1 → 扰动 ∝ σ²（单点全吸收）；
- top-k：∝ σ²/k；quantile-q：∝ σ²/(qN)。

**理论预测**：袋级回归噪声下，池化越硬（n_eff 越小），噪声敏感性越高——与文档假设方向相反。文献辩证：Duffner 2020 在**实例级单向翻牌噪声**（分类）下得出"噪声大→硬度大优"的结论；我们的噪声是**袋级回归目标噪声**——两种噪声模型导出相反结论，本实验即裁决这一张力。

**实验设计**：7 池化变体（mean / gmean-p5 / LSE-τ1 / top-50 / max / attention / quantile-q75）×（1 干净 + 均匀{0.15,0.3} + 离群{0.2,0.5}）× 5 折 × 3 种子 = 35 组 525 次训练；仅面积约束 MSE（隔离池化单变量）；噪声仅污染训练标签（D'Amato 协议）；固定种子与超参（Grahn 纪律）。

## 3. 实验结果

**干净基线排序**：gmean_p5 (0.729) > q75 (0.644) > lse_t1 (0.623) > attention ≈ mean (0.599) > top50 (0.518) > max (0.359)。

**噪声退化**（Pearson，uniform 0.3 / outlier 0.2 / outlier 0.5）：
- 软池化曲线平坦：mean 0.599→0.589/0.565/0.587；q75 0.644→0.643/0.624/0.598；attention 甚至略升（0.599→0.676/0.612/0.548）；
- 硬池化崩塌：max 0.359→0.399/**0.132**/0.306；top50 0.518→0.418/0.438/0.397。

**硬度-方差对照**（n_eff 实证：参与率 (Σ|w|)²/Σw²）：top50（n_eff=50）MAE 增量最大（+0.0117）；软池化（n_eff≈2500–9600）增量≈0 或为负——与理论预测 σ²/n_eff 方向一致。

**三问的回答**：
1. 池化越硬，对袋级标签噪声越敏感（与文档假设相反）；
2. 估计误差方差 ∝ σ²/n_eff，得到 top50/max 的实证支持；
3. 离群值噪声下软池化（mean/q75/gmean）损失最小；max 损失最大。

## 4. 最关键的阻塞点

MAE 增量指标对小退化不敏感（干净误差地板 0.15 掩盖小幅退化）——硬度-方差对照在 Pearson 保持率上更清晰；此外 25 张的绝对噪声水平有限，结论的统计强度受队列规模约束（已在笔记中声明）。
